# My Study Hub

Quero criar um site/aplicativo que funcione como um banco de questões, onde eu possa cadastrar minhas questões e utilizar para revisar/estudar. Ele pode ter um gráfico de desempenho. Precisa ter um banco de dados bom. Precisa ter entrada com cadastro/login. Porém quanto ao cadastro, somente o admin poderá fazer. O login se dará com os dados gerenciados pelo admin. Cada um terá sua conta com seus dados e gráficos.
